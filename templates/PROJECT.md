# 프로젝트 설정 템플릿

이 문서는 예시 입력 양식이다. 기존 문서·manifest·CI에서 확인되는 값부터 채우고 현재 작업에 불필요한 빈칸은 질문하지 않는다. 설정은 권한을 부여하지 않는다.

- 목적·산출물:
- 작업 범위·제외 범위:
- 기존 지침·아키텍처 문서:
- 영역·경로·기술: 단일 영역이면 한 줄로 충분. 여러 영역이면 아래 표 사용.
- Git: 기본 브랜치·머지 관례·기존 승인 범위
- 자원 한도: 실제 합의한 시간·비용·시도 횟수. 미설정 값은 임의로 만들지 않음.
- 완료 증거·중단 시 보존할 결과:
- 작업 기록: ai-input/worklog/YYYY-MM/YYYY-MM-DD.md (ai-input 전체 ignore)

PHP·Next.js·Spring 등 이름만으로 명령을 채우지 않는다. composer.json, package.json, pom.xml, build.gradle, CI 및 실제 문서를 확인한다. 외부 DB·API·계정이 필요한 검증은 부작용과 권한을 확인한다.

큰 프로젝트에서 지도를 유지한다면 기준 커밋·확인 날짜·근거 파일을 함께 두고 변경된 경계만 갱신한다. 별도 지도 구축을 모든 작업의 필수 선행 단계로 만들지 않는다.
