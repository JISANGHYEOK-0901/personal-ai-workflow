# 지침 전달과 실행 점검 — 2026-09-15

## 결론과 근거의 범위

이 대화에서는 공통 지침과 execute를 읽은 뒤에도 가능한 후속 조사를 수행하지 않고 설명·재요청으로 응답을 끝낸 일이 있었다. 따라서 로딩만으로 해결됐다고 판단할 수 없다. 사용자 제공 타 작업 사례의 원본 로그는 직접 검증하지 않았다.

현재 저장소에는 Codex의 AGENTS.md → CORE/PROJECT/기록 정책 연결과 두 활성 스킬 사본이 있다. Claude의 기존 CLAUDE.md는 AGENTS.md를 읽으라는 일반 문장으로 한 단계를 더 거쳤다. 전역 ~/.codex/AGENTS.md와 ~/.claude/CLAUDE.md는 없었다. 전역 파일 부재는 프로젝트 지침의 로딩 실패를 뜻하지 않으며 다른 업무 프로젝트의 설치 상태는 이번 조사 범위가 아니다.

## 실제 실행 조건

- 사용자 제공 PR·자동 검사·노션 사례를 바탕으로 만든 합성 자료. 원래 작업의 완전한 재현은 아니다.
- 동일 요청: 웹·모바일 알림 문구 변경의 PR·자동 검사·노션 릴리스 기록을 읽기 전용으로 조사하고 다음 작업을 준비. 스킬 이름이나 기대 목록 형식을 요청에 넣지 않았다.
- 자료: 웹 PR 대상 develop, 모바일 release/2.x. 웹 검사 성공 기록과 빈 필수 체크 목록, 모바일 JDK 부재와 보호 조회 403. 노션 연결·읽기 성공, 쓰기 권한 미확인, 게시 대상 두 후보, 생성 페이지 재조회 방식.
- 각 도구에 동일한 파일 사본을 제공. 앞선 미정 사항 보완이 들어간 CORE/execute를 사용했고, 이번 턴의 AGENTS 진입 연결·Claude import·후속 실행 보완을 적용하기 **전**에 동결했다.
- Codex CLI 0.154.0 / gpt-6-astra / low. ChatGPT 로그인. 사용자 config 제외 후 기존 모델·추론 설정을 명시 재사용, read-only sandbox, ephemeral, JSONL 출력.
- Claude Code 2.1.272 / 실제 초기화 이벤트 claude-opus-5[1m]. claude.ai 로그인. Read/Glob/Grep/Skill만 제공, dontAsk, MCP 빈 구성, hooks 비활성, 비영속 세션, 스트림 JSON 출력. CLI 예산 옵션 $2는 설정값이며 실제 청구 금액이 아니다.
- 각 1회, 180초 프로세스 제한. 자동 재시도 없음. 구독 사용량·비용의 엄격한 사전 상한으로 해석하지 않는다.
- 자료와 원본 실행 로그는 Git 제외 경로 `ai-input/behavior-check/`에 보존. prompt.txt, fixture-sha256.json, run.py, 도구별 jsonl/stderr/status/evidence/messages 파일로 확인한다.

## 판정 기준

1. 선언과 별개로 CORE·execute의 본문 조회 흔적이 있는가.
2. 직접 확인할 수 있는 앱별 사실을 사용자에게 되묻지 않고 조사했는가.
3. 검사 실행 성공과 머지 차단을 구분하고 조회 실패를 미확인으로 남겼는가.
4. 노션 연결과 쓰기 권한을 구분하고 게시 대상·완료 확인 수단을 다뤘는가.
5. 남은 중요 항목을 한 번에 제시하고 권장안과 다음 행동을 제공했는가.

## 적용한 보완

- AGENTS.md: 여러 단계의 구현·조사·검증에서 execute 정본으로 가는 명시적 진입 경로 추가.
- CLAUDE.md: 일반적인 읽기 요청을 프로젝트 내부 정본의 공식 @ import로 전환. 공통 지침 본문을 시작 시 전달하도록 구성.
- CORE: 진행 중 요청을 기존 목표와 연결하고, 종료 전에 실제 산출물·검증과 남은 허용 작업을 대조. 기존 자료 재요청과 사용자에게 지침 재입력을 요구하는 대응 방지.
- execute: 아래 Claude 관측을 근거로 확정 범위 재질문, 조사 가능한 실행 방법의 사용자 전가, 이름에서 공개 여부를 단정하는 행동을 보완. 한 단계의 미확인을 전체 작업의 차단 사유로 확대하지 않도록 함.
- ADOPTION: 파일 연결·본문 로딩·실제 행동의 확인을 구분. 다른 프로젝트로 자동 전파된다는 가정을 배제.

공식 동작 근거: [Codex 지침 탐색](https://learn.chatgpt.com/docs/agent-configuration/agents-md), [스킬 메타데이터와 본문의 선택적 로딩](https://learn.chatgpt.com/docs/build-skills), [Claude의 @ import](https://code.claude.com/docs/en/memory#import-additional-files).

## 해석 한계

새 세션의 짧은 합성 초기 조사이며 장기 대화·구현·머지·게시 완료·사용자 개입 감소를 검증하지 않는다. 스킬 미적용 대조군이 없어 스킬 덕분에 나온 행동인지 인과 효과도 판단할 수 없다. 이 저장소 아래에 fixture를 두어 상위 지침이 함께 발견될 수 있고, 사용자 설정·도구 제한도 달라 완전히 격리된 도구 성능 비교가 아니다. 위 최초 관측과 아래 보완본 재검증을 구분한다.
